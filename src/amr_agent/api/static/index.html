AMR Research Agent

by Pablo Estepa · LinkedIn
Source code Evals amr-mcp on PyPI API docs

Ask about antimicrobial resistance. Answers come from ~3,000 recent PubMed abstracts and NCBI's gene catalog, and every citation is checked against what was actually retrieved.

How it works
  1. Your question is searched two ways over ~3,000 PubMed abstracts (2022–2026): Postgres full-text for exact terms and pgvector embeddings for meaning, merged with reciprocal rank fusion.
  2. An LLM (gpt-oss-120b on Groq) answers only from the abstracts it was given and cites them by PMID.
  3. Every cited PMID is checked against what was retrieved. Any other PMID is flagged as unverified.
  4. In agent mode the model runs a loop of up to 5 rounds and chooses its tools: the same literature search, or NCBI's gene catalog, protein records and PubMed through amr-mcp, an MCP server I wrote.
  5. Papers mode is not limited to AMR: the agent searches all of PubMed, then reads the full text of the best match from PubMed Central and ranks its paragraphs with BM25, because exact figures are rarely in the abstract.
Mode

The search index is English-only, so English questions find more. The answer will still be in your language.

Questions and answers are logged to debug the agent, so leave out personal details.

All eval results Design decisions

A research tool, not clinical advice. Answers come only from the indexed abstracts, NCBI's databases and PubMed Central, and can still be wrong: check the cited papers.

Runs on free tiers (Render, Neon, Groq): after a quiet spell the first question can take up to a minute, and the LLM quota is shared by every visitor.

Each question is traced with OpenTelemetry and stored in Langfuse: the question, the answer, the tools the agent called with their arguments, and token counts. No account or IP address goes into these traces. They are used to find and fix failures.
