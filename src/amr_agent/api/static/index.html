AMR Research Agent

Questions about antimicrobial resistance, answered only from ~3,000 recent PubMed abstracts with every claim cited (hybrid search with pgvector + Postgres full-text and an LLM on Groq). In agent mode, the model also queries NCBI's gene catalog and protein databases through an MCP server.

The agent decides which tools to call (literature search, NCBI gene catalog, species that carry a protein, PubMed metadata) and shows every step. It uses more of the free LLM quota, so it is limited to a few questions per minute.
